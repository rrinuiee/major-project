## 🎯 How to Use

### 1. Start the App
```bash
npm run dev
```

### 2. Navigate to Navigation Screen
- Splash → Login → Home → Click "Start Navigation"

### 3. Search for a Location
- Type in search box: "Lulu Mall Kochi" or any place
- Wait for suggestions (appears in ~500ms)
- Click on your desired location

### 4. View the Route
- Map shows:
  - 📍 Your location (blue marker)
  - 🎯 Destination (red marker)
  - Green line (route)
  - Distance & time

### 5. Start Navigation
- Click "Start Ride" button
- See turn-by-turn directions
- Follow instructions
- Map updates as you move

## 🐛 Troubleshooting

### Map not showing?
```bash
npm install leaflet react-leaflet@4.2.1 axios --legacy-peer-deps
npm run dev
```

### Search not working?
- Check internet connection
- Wait 500ms after typing
- Try more specific search terms

### Route not calculating?
- Make sure you selected a destination
- Check if both markers appear on map
- Try searching again
